# Thumbnail Insights

La evolución del Caption se desarrolla en [`studio/`](studio/README.md): herramientas de análisis visual, comparación, proyectos y experimentos de CTR para creadores UEFN.

El frontend anterior se conserva en `index.html` y `style.css`. El nuevo estudio tiene una publicación privada independiente para probarlo antes de actualizar el despliegue público.

La clave OpenAI existente se configura como secreto del servidor; no forma parte del repositorio.
